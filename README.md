# Hi, I'm Quinn 👋

I build **accessibility-first software** with a focus on making games and everyday technology easier to use for blind and low-vision users.

I started creating accessibility tools because I kept running into real problems that existing software did not solve well enough. Rather than waiting for the perfect tool to appear, I decided to start building the kinds of things I wanted to use myself.

## 💜 Echoes Unseen

My main public project is **[Echoes Unseen](https://github.com/Quinn80/EchoesUnseen)**, a free and open-source accessibility companion built for **Guild Wars 2**.

It brings together features such as screen reading, the Hover Reader, Chat Reader, navigation assistance, voice tools, customizable accessibility settings, and other systems designed to make information easier to access without taking control away from the player.

## What I care about

- 🎮 Game accessibility
- 🔊 Voice-first interfaces
- 👁️ Screen-reader and low-vision friendly design
- 🧭 Accessible navigation and guidance
- ♿ Building accessibility in from the beginning, not adding it as an afterthought
- 🔒 Keeping features local and private where practical
- 🧪 Testing accessibility features against real-world use instead of assuming they work

## How I like to build

I prefer tools that are understandable, practical, and respectful of the person using them.

That means clear interfaces, plain language, strong keyboard and screen-reader support, thoughtful low-vision design, and features that help without getting in the user's way.

I'm still learning, experimenting, and refining things as I go, but I care a lot about building software that solves real problems and sharing what works with other people who may need it too.

## Current focus

Right now I'm especially interested in:

- accessible game overlays and navigation
- screen reading and OCR
- voice interaction and spoken feedback
- responsive low-vision interfaces
- tools that make complicated workflows easier to use

Echoes Unseen is my main public project today, with more accessibility-focused work to come.
