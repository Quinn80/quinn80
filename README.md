# Hi, I'm Quinn 👋

I build **accessibility-first software**, with a focus on making games and everyday technology easier to use for blind and low-vision users.

## 💜 Echoes Unseen

**[Echoes Unseen](https://github.com/Quinn80/EchoesUnseen)** is a free, open-source accessibility companion built for **Guild Wars 2**.

It brings together tools such as screen reading, the Hover Reader, Chat Reader, navigation assistance, voice features, and customizable accessibility settings in one Windows app.

🌐 **Website:** [echoesoftyria.com](https://echoesoftyria.com)  
💻 **Project:** [github.com/Quinn80/EchoesUnseen](https://github.com/Quinn80/EchoesUnseen)
